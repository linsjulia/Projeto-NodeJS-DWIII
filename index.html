Apresentação do Projeto desenvolvido em Node.jS

3º Semestre - DSM - Fatec Diadema

Integrantes: Júlia Lins | Vitor Romualdo

Contexto

O projeto a seguir tem por objetivo desenvolver um servidor web com rotas contendo páginas HTML utilizando as competências e ferramentas aprendidas na aula de Desenvolvimento Web III pelo professor Vinicius Heltai

Além disso, realizar uma apresentação pessoal de cada integrante do projeto aplicando estas competências de aprendizado

Competências e ferramentas utilizadas:

Node.js:

  • Sistemas de Rotas
  • Módulo File System
